## One-Time Setup

```bash
cd ai-engineering-journey/rag-study-buddy
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Then set up your API key:

```bash
cp .env.example .env
# open .env and paste your real Groq key in place of "your-groq-api-key-here"
```

(Get a key from a free account at console.groq.com. It is never committed — `.env` is already in `.gitignore`.)

## Every Work Session

Each new terminal window starts fresh — `cd` and an active `venv` do not carry over from a previous window.

```bash
cd ai-engineering-journey/rag-study-buddy
source venv/bin/activate
```

You will know it worked when your prompt shows `(venv)` at the start.

## Building / Rebuilding the Index (Step 3)

```bash
python3 build_index.py
```

If you need a clean rebuild (for example, after changing `vector_store.py`), clear the old index first — Chroma locks in settings like the distance metric at creation time, so a code fix alone is not enough to apply retroactively:

```bash
rm -rf data/vector_store
python3 build_index.py
```

## Asking a Question / Running the Evaluation (Step 5)

```bash
python3 -m src.search        # a sanity-check question, run as a module
python3 run_eval.py          # runs all 19 questions from data/eval_questions.json
```

Note: `python3 src/search.py` (run directly, not as a module) fails with `ModuleNotFoundError: No module named 'src'`, because Python treats the file's own folder as the reference point for imports when a script is run that way. Running it as `python3 -m src.search` from the `rag-study-buddy/` folder fixes this.

## Git Workflow

```bash
git status                          # always check this first
git add <one file at a time>        # e.g. git add src/search.py
git commit -m "a clear message"
git push
```

Two real gotchas worth remembering from this project:

- Type `git commit -m "..."` and `git push` as two separate lines. Pasted or typed as one line, the shell may run only the first command and treat the rest as invalid arguments.
- `.gitignore` lives one level up, at the `ai-engineering-journey/` root — not inside `rag-study-buddy/`. From inside `rag-study-buddy/`, that means `git add ../.gitignore`.

After pushing, it is worth verifying rather than assuming it worked:

```bash
git log -1 --stat
git fetch origin
git log origin/main -1
```
